# VEYRA 1.2.132

- Padding, typography and corner radius are tightened so the controls cover less of the camera image while retaining the same runtime states and colors.

No runtime-control backend, Live transport, detector, Light Threat, IR Transition Guard, recording or protected deployment-file behavior changed.
